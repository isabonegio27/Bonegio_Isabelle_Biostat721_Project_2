# Air Pollution in Durham County, NC between 2018 and 2020

Isabelle Bonegio: BIOSTAT 721 Project 2

## Description

This project analyzes daily air quality data (CO, PM2.5, and O3)
as part of a study on associations between air pollution and
sickle cell disease (SCD) in Durham County, North Carolina.

## Data Source

Daily air quality measurements from the U.S. EPA air pollution monitor at
Raleigh-Durham International Airport (RDU), 
covering January 2018 through April 2020.

## File Structure

- `data` = three EPA data files
- `Isabelle_Bonegio_Project2.Rmd` = R Markdown file with all code
- `Isabelle_Bonegio_Project2.docx` = final knitted Word report
- `Bonegio_Isabelle_Biostat721_Project2.Rproj` = RStudio project

## How to Reproduce

1. Clone this repository and open
  `Bonegio_Isabelle_Biostat721_Project2.Rproj` in RStudio.
  
2. Install the required packages:
   ("tidyverse", "knitr", "NatParksPalettes")
   
3. Open `Isabelle_Bonegio_Project2.Rmd` and click Knit 
   to generate the Word report.
